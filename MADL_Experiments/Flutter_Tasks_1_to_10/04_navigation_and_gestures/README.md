# Experiment 4 — Navigation and Gestures

## Aim
Use Navigator routes and GestureDetector interactions.

## Files
- `lib/main.dart` — application source
- `pubspec.yaml` — Flutter project configuration

## Run
From this folder, run `flutter create .` to generate platform folders if they are not present, then run `flutter pub get` and `flutter run`.

## Expected result
Run the app on an emulator or connected device and interact with the screen to verify the feature described in the aim.
