# Flutter Tasks 1–10

This bundle contains ten beginner-friendly Flutter experiment source folders. Each experiment includes a `lib/main.dart`, `pubspec.yaml`, and its own README.

## Experiments
1. Hello World
2. Widgets and Layout
3. User Input Form and Validation
4. Navigation and Gestures
5. ListView
6. Stateful Counter
7. Simple Calculator
8. Checkbox and Settings
9. Profile Card
10. Quiz App

## Important
These are starter implementations based on common beginner Flutter topics. If your college has an official lab manual with different task titles or requirements, use that manual as the source of truth and adjust the experiments accordingly. The bundle does not include generated Android/iOS platform folders.

## Run an experiment
1. Install Flutter and verify with `flutter doctor`.
2. Open a terminal in the experiment folder.
3. Generate the platform scaffolding in that folder by running `flutter create .`
4. Run `flutter pub get`
5. Run `flutter run`

If `flutter create .` asks about overwriting existing files, do not overwrite `lib/main.dart` or `pubspec.yaml`; keep the supplied experiment source and configuration.
